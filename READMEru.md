Anixart X (Неофициальный клиент)

[🇬🇧](https://github.com/VictimZxc/Anixart-X/blob/main/README.md)

Неофициальный кроссплатформенный клиент для сервиса Anixart — удобный просмотр аниме, управление списками, избранным и коллекциями.

## 📌 Возможности

- ✅ **Каталог аниме** – новинки, популярные тайтлы, поиск по жанрам  
- ✅ **Расширенный поиск** – фильтр по году, статусу, рейтингу  
- ✅ **Избранное** – сохраняйте любимые аниме  
- ✅ **История просмотров** – продолжайте с того места, где остановились  
- ✅ **Комментарии и оценки** – обсуждения и отзывы сообщества  
- ✅ **Уведомления** – оповещения о выходе новых серий  
- ✅ **Настраиваемый плеер** – выбор качества, субтитры, горячие клавиши
- ✅ **Адаптивный интерфейс** – удобный дизайн для ПК (Windows/Linux) и смартфонов (Android/iOS)

## 📥 Установка

### 🪟 Windows:
1. Скачайте последнюю версию из **Releases**  
2. Запустите `Anixart X.exe`  
3. Следуйте инструкциям установщика  

### 🐧 Linux (Flatpak):
1. Скачайте `.flatpak`-пакет из **Releases**  
2. Откройте терминал в папке с файлом  
3. Установите приложение:  
   ```bash
   flatpak install --user AnixartX.flatpak
4. Запустите командой:
   ```bash
   flatpak run com.anixart.AnixartX

###📱 Android:
1. Скачайте актуальный файл `.apk` (например, `Anixart X.apk`) из раздела **Releases**  
2. Установите APK-файл на устройство  
3. При необходимости разрешите установку из неизвестных источников

### 🍎 iOS:
1. Скачайте актуальный `.ipa` файл из раздела **Releases**  
2. Установите приложение на устройство одним из удобных способов:

- **С помощью TrollStore** *(iOS 15.0 – 17.0, бессрочная подпись)*:
  Откройте скачанный `.ipa` через TrollStore и нажмите **Install**.

- **С компьютера на Windows (через Sideloadly / AltStore)**:
  Используйте [Sideloadly](https://sideloadly.io/) или [AltStore](https://altstore.io/) для установки `.ipa` на телефон.  
  *(Без платного сертификата разработчика подпись действует 7 дней)*.

- **С компьютера на macOS (через iOS App Signer / Xcode)**:
  Подпишите `.ipa` через [iOS App Signer](https://dantheman827.github.io/ios-app-signer/) со своим Apple ID и установите через Xcode или Apple Configurator.  
  *(Без платного сертификата разработчика подпись действует 7 дней)*.

⚙️ Системные требования

    ### 💻 ПК (Windows / Linux)
    - **ОС:** Windows 10/11 (64-bit) или Linux (с поддержкой Flatpak)
    - **ОЗУ:** 2 ГБ+
    - **Диск:** 300 МБ

    ### 📱 Мобильные устройства (Android / iOS)
    - **Android:** Android 7.0 (Nougat) / API 24 или новее
    - **iOS:** iOS 15.0 или новее
    - **Диск:** 50 МБ

⚠️ Важно

    Это неофициальный клиент, не связанный с официальным Anixart.

    Для работы требуется аккаунт Anixart.

    Некоторые функции мобильного приложения могут отсутствовать.
